Climate Weather Dashboard - Setup & Run Instructions

Project Structure:
climate_weather_dashboard/
├── index.html       # Main HTML file
├── style.css        # Separate stylesheet file for styling and responsiveness
├── script.js        # JavaScript file containing app logic & API integration
└── README.txt       # Setup and run instructions

API Configuration:
- OpenWeatherMap API key is configured inside 'script.js' at the top (`CLIMATE_API_KEY`).
- You can easily update or replace your API key directly in 'script.js'.

How to Run:
1. Extract the ZIP file.
2. Open 'index.html' in any web browser.
